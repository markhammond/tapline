## The caption in a font of your own — not included

`Waveform:TaglineFont` (or `WAVEFORM_TAGLINE_FONT`) sets the caption under the ridges in a font file on this machine —
e.g. Måns Grebäck's *Maryson Print*, which its Product Usage Agreement (<https://www.mansgreback.com/pua>) allows for
personal use only, without sharing the file or putting it "on Internet or any network". So no such font is bundled:
the sample serves the file you name (`/tagline-font/{fingerprint}`) to a browser on this machine alone, and a viewer
anywhere else —
and everyone, without it set — sees the caption in its theme's font. A public deployment with it set would still need
the
font's commercial (webfont) license.

## Book of Shapes — Joy Division

The ridge field (`Waveform/Ridges.cs`) follows the approach and the parameter values of the "Joy Division" pattern by
Nikolaj Sokolowski, <https://bookofshapes.com/patterns/joy_division> — inspiration only; no code was used.
